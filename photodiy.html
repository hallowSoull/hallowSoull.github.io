DIY Photoshop - Make Your Own Christmas Tree!

Create a custom Christmas tree utilizing code from 'processing'

Click on the following keys on your keyboard to create your very own Christmas tree!

1 = click your mouse anywhere to spawn a blue sky

2 = click your mouse anywhere to spawn a tree template

3 = click your mouse anywhere to spawn a tree stump

4 = click your mouse anywhere to spawn snow

5 = click and drag your mouse to draw red tinsel on your tree

6 = click and drag your mouse to place christmas ornaments on your tree

7 = click and drag your mouse to draw white tinsel on your tree

8 = click and drag your mouse to place snowflakes around your tree

9 = click and drag your mouse to place presents around your tree

0 = click and drag your mouse to place bows on your presents and tree

Here's the code!

function draw() {
  if (keyIsPressed) {
    choice = key; // set choice to the key that was pressed
    clear_print(); // check to see if it is clear screen or save image
  }
  if (mouseIsPressed){
    newkeyChoice(choice);  // if the mouse is pressed call newkeyChoice
  }
}

function clear_print() {
// this will do one of two things, x clears the screen by resetting the background
// p calls the routine saveme, which saves a copy of the screen
  if (key == 'x' || key == 'X') {
    background(screenbg); // set the screen back to the background color
  } else if (key == 'p' || key == 'P') {
     saveme();  // call saveme which saves an image of the screen
  }
}

function saveme(){
    //this will save the name as the intials, date, time and a millis counting number.
    // it will always be larger in value then the last one.
  filename=initials+day() + hour() + minute() +second();
  if (second()!=lastscreenshot) { // don't take a screenshot if you just took one
    saveCanvas(filename, 'jpg');
    key="";
  }
  lastscreenshot=second(); // set this to the current second so no more than one per second
  
}
